## Contributing

### Branch strategy
- main: stable releases
- dev: integration branch
- feature/<ID>-<short-title>: feature branches

### Commit convention
Use Conventional Commits:
- feat: new feature
- fix: bug fix
- docs: documentation
- chore: maintenance
- test: add/update tests

### Definition of Done
- Tests pass (unit/integration if applicable)
- Lint/format passes
- Docs updated if needed
- No raw datasets or secrets committed
